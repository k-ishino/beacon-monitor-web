シリアルポートは 1 ページしか掴めないため、このページを開いた時点で モニタ側の接続は自動的に解放されます。手動で切断する必要はありません。書き込みが 終わってこのページを離れると、モニタは自動で繋ぎ直します。

ファームウェアを書き込む

ESP32-C3 のネイティブ USB ポート（USB-UART ブリッジ側ではありません）を PC に挿してから、下のボタンを押してポートを選択してください。

このブラウザは書き込みに対応していません。デスクトップ版の Chrome / Edge を お使いください。 書き込みには HTTPS または localhost が必要です。

書き込みが終わったらダイアログを閉じてモニタに戻ってください。 ボードは再列挙されますが、モニタが自動で繋ぎ直します。

Windows — 初回接続時に usbser.sys が自動で当たり、 デバイスマネージャの「ポート (COM と LPT)」に USB シリアル デバイス (COMx) が出ます。出ない場合は「USB JTAG/serial debug unit」を右クリック → ドライバーの更新 → コンピューターを参照 → 一覧から選択 → USB シリアル デバイス を選んでください。

macOS — ドライバは不要です。OS 標準の CDC-ACM が担当し、 /dev/cu.usbmodem* として現れます。
